# sds/ (vendored)

Built copy of the Studioesque Design System's `dist/` (commit 2dec858). Don't edit
these files here: change the system, run `npm run build` there, and copy `dist/` over
this folder. Pages load `sds.min.css`, `sds-brackets.min.css` and `sds.min.js`;
`assets/` must stay next to the CSS.
