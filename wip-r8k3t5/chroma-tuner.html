Chroma tuner

Each ramp uses the current --l-NN, --c-<family>-NN and --h-<family> values from colors.css. Edit the chroma at 05, the peak and 95 (and move the peak step); steps in between keep the original curve's shape. Outlined swatches are anchors. P3 = outside sRGB but inside Display P3 (shows fully on Mac/iPhone screens, slightly dulled on standard sRGB ones); ! = outside both, clipped on every screen. Edits are saved in this browser until reset. Copy the CSS below into colors.css to apply them.

CSS for colors.css

Replaces the per-family chroma blocks (from /* blue (H=252) */ to the last --c-…-max line) in the /* CHROMA */ section.
